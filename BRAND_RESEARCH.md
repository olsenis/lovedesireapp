## 2. Trademark search

Searched for exact match "Love Desire" as software / mobile app in relevant jurisdictions:

- **USPTO (US):** No hits for "Love Desire" in relevant classes (Class 9 downloadable software, Class 42 SaaS, Class 45 dating services). Nearby marks: "LOVE" (owned by Morgan Art Foundation for physical art works — Class 6, not software), "LOVE IS LOVE", "LOVE ME BRAND" — none conflict.
- **EU (EUIPO / TMview):** Direct search hit an error, but Google's index of EU marks returns no "Love Desire" software mark.
- **Iceland (ISIPO / Hugverkastofan):** Nothing found. Icelandic "LOVE Synthesizers" trademark exists but is for synthesizer hardware — unrelated.
- **Nordic (Norway NIPO, Denmark DKPTO):** No hits.

Word "Love" alone is deemed too generic to trademark exclusively. "Love Desire" as a compound is registrable but nobody has done it in the software space.

**Recommendation:** Safe to use pre-launch. Consider filing a trademark application in Class 9 + Class 42 for `Love Desire` post-launch if we get real traction (~$350 USPTO filing fee + optional attorney, or ~€200 EUIPO for EU-wide). Not launch-blocking.

## TL;DR

**Verdict: SAFE to use "Love Desire" and register `lovedesireapp.com`.**

- ✅ No trademark blocks in US, EU, or Nordic jurisdictions
- ✅ Primary domain `lovedesireapp.com` is free and cheap (~$12/yr)
- ✅ No existing app claims the exact name
- ✅ No dominant social handles taken
- ⚠️ Crowded "Desire" family in the couples-app space (3-4 tangential competitors) — differentiation is on brand tone + feature set, not name
- ⚠️ `lovedesire.com` is squatted at premium — accept and move on with `.app`-postfixed variant

**Action items:**

1. Register `lovedesireapp.com` at Namecheap / Cloudflare / Vercel (~$12/yr, 5 min)
2. Defensively register `lovedesire.app` + `lovedesire.io` (~$40-60/yr total, 10 min)
3. Grab `@lovedesireapp` on Instagram, TikTok, Twitter/X, YouTube (15 min)
4. Add domain to Vercel project #2 (web/) once purchased
5. Consider USPTO Class 9 + Class 42 trademark filing 3-6 months post-launch if the app gains traction (~$350 USPTO filing fee)

**Don't do:**
- Chase `lovedesire.com` premium (expensive, adds no real value over `.app`)
- File trademark pre-launch (premature; costs money for zero benefit before we have users)
- Worry about the defunct Japanese band or dissolved UK fashion company
